# 本地启动与测试指南

> 适用对象：在自己电脑上跑这个项目的人（参赛成员 / 评审复现）。
> 全程约 10 分钟（首次启动多一个模型下载，约 2~5 分钟，取决于网速）。

---

## 一、开始前：确认四个软件

| 软件 | 版本要求 | 检查命令（CMD 里执行） | 预期输出 |
|---|---|---|---|
| JDK | 17 | `java -version` | `openjdk 17.x.x` |
| Maven | 3.9+ | `mvn -v` | `Apache Maven 3.9.x` |
| MySQL | 8.0+ | `net start` 列表里有 MySQL，或直接进 `mysql -u root -p` | 能连上 |
| Node.js | 18+ | `node -v` | `v18.x` 或更高 |

缺哪个装哪个。MySQL 要**先确保正在运行**（Windows 服务里启动，或 `net start MySQL`）。

---

## 二、配置密钥（只做一次）

程序要调智谱大模型，必须有一个 API Key：

| 变量名 | 必填 | 说明 |
|---|---|---|
| `ZHIPU_API_KEY` | ✅ 必填 | 智谱开放平台的 Key，<https://open.bigmodel.cn> → 控制台 → API Keys 复制 |
| `DB_PASSWORD` | ❌ 选填 | 你的 MySQL root 密码；不配就尝试空密码连接 |

**配置步骤**（Windows）：

1. `Win + S` 搜「编辑系统环境变量」→ 打开 → 点「环境变量」按钮
2. 在「用户变量」区点「新建」
3. 变量名填 `ZHIPU_API_KEY`，变量值填你的 Key → 确定
4. 如果有 MySQL 密码，同样新建 `DB_PASSWORD`
5. **重启 IntelliJ IDEA / CMD**（不重启读不到新变量）

> ⚠️ **坑 1**：改完环境变量不重启 IDE，程序一定报「缺少环境变量 ZHIPU_API_KEY」。这不是代码坏了，是 Java 只在启动时读一次环境变量。
>
> ⚠️ **坑 2**：缺 Key 时启动会直接退出并打印中文解决办法（这是故意的设计，见 `AiwebApplication.java`），照着做就行。

---

## 三、启动后端（先启它！）

**为什么必须先启后端**：前端页面要靠后端提供数据，后端没起时页面右上角会显示「后端未连接」。

### 方式 A：一键脚本（推荐，不用记命令）

双击项目里的：

```
scripts\start-backend.bat
```

### 方式 B：命令行

```bash
cd 项目目录\aiweb
mvn spring-boot:run -Dspring-boot.run.arguments=--server.port=8080
```

### 方式 C：IntelliJ IDEA

打开 `AiwebApplication.java` → 右键 Run。如果日志里 Tomcat 端口不是 8080，在运行配置的「程序参数」里加 `--server.port=8080`。

### 怎么算启动成功

日志出现这两行就是成功了：

```
Started AiwebApplication in x.xxx seconds
Tomcat started on port 8080
```

启动过程会自动做四件事（不用你管）：建数据库和表 → 导入院校数据 → 导入三科题库 → 构建 RAG 向量库。首次启动会从 hf-mirror 下载 e5 嵌入模型（约 100MB），**需要联网**，下次启动用缓存。

> ⚠️ **坑 3：端口被抢**。如果日志里 Tomcat 端口不是 8080 而是别的数字，说明环境里有 `SERVER_PORT` / `SERVER__PORT` 之类的变量抢了端口（它的优先级比配置文件高）。解法就是上面命令里的 `--server.port=8080`（命令行参数优先级最高，能压过环境变量）。一键脚本已经带上了。
>
> ⚠️ **坑 4：首次启动慢**。下载模型 + 建向量库，耐心等 1~3 分钟，别以为卡死了。

## 四、启动前端

后端起来后，双击：

```
scripts\start-frontend.bat
```

首次运行会自动用国内镜像装依赖（1~2 分钟）。或者手动：

```bash
cd 项目目录\aiweb\frontend
npm install --registry=https://registry.npmmirror.com   # 仅首次需要
npm run dev
```

看到 `Local: http://localhost:5173/` 就成了。

> ⚠️ **坑 5**：前端必须通过 `npm run dev` 打开（地址栏是 localhost:5173）。直接双击 `dist/index.html` 打不开——那种方式没有 dev server，接口代理不工作。

## 五、打开页面，按这个路线测

浏览器访问 **http://localhost:5173**，右上角状态点应该是**绿色**（「服务正常」）。

| 顺序 | 页面 | 测什么 | 正常表现 |
|---|---|---|---|
| 1 | 首页 | 统计卡数字 | 显示院校 28 / 专业 104 / 题目 84（加载时先出骨架屏） |
| 2 | 院校专业库 | 筛选 + 详情 | 选「青岛 + 211」能筛出 2 所；点院校名弹出专业抽屉 |
| 3 | 学情诊断 | 完整答题闭环 | 选「英语」→ 开始测评 → 答几题提交 → 出掌握度诊断（先答 1 对 1 错，看百分比变化） |
| 4 | 备考计划 | 学科切换 | 切「英语」显示刚才的诊断；切「政治」提示未测评（因为没答过） |
| 5 | 认知科普 | 双栏 + 答疑 | 左侧 7 个主题切换阅读；右侧问「学硕专硕区别」，回答附参考来源 |
| 6 | AI 规划 | Agent 编排 | 输入「山东有哪些985院校」→ 看 5 步轨迹逐条播放 → 出汇总建议 |
| 7 | AI 问答 | 多轮对话 | 连续追问，带上下文 |

**进阶测试**（给想深入的人）：

- **图片作答**：学情诊断里填空题点「上传答案图片」，手写答案拍照上传
- **MCP 工具**：用 Cherry Studio 等客户端连 `http://localhost:8080/sse`，看 5 个工具能否被调用（README 第九节有配置）
- **接口文档**：访问 <http://localhost:8080/swagger-ui.html>
- **单元测试**：`cd aiweb && mvn test`，35 个用例应全绿

## 六、常见问题速查

| 现象 | 原因 | 解决 |
|---|---|---|
| 启动报「缺少环境变量 ZHIPU_API_KEY」 | 密钥没配或没重启 IDE | 见第二节 |
| 页面右上角「后端未连接」 | 后端没起 / 端口不对 | 先启后端；看日志 Tomcat 是不是 8080 |
| 页面空白、控制台报接口错误 | 不是通过 `npm run dev` 打开的 | 用 localhost:5173 访问 |
| `Access denied for user 'root'` | MySQL 有密码但没配 `DB_PASSWORD` | 配上并重启 IDE |
| AI 回答变成「大模型接口暂时不可用」 | 免费档限流（正常现象） | 稍后重试；已按设计降级，不影响其他功能 |
| 数学测评只抽到 30 题 | 老数据库里的存量数据 | 清空 `question_bank` 表里数学题后重启，会重新导入 34 题 |

## 七、停止项目

在两个命令行窗口按 `Ctrl + C`（或直接关窗口）即可。数据都在 MySQL 里，下次启动还在。
