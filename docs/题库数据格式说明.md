# 题库数据格式说明

本文档定义「智能出题与学情诊断」模块统一使用的题目数据格式。
后续所有批次（数学第二、三批，以及英语、政治）都遵循同一格式，保证导入器、掌握度算法、前端展示无需改动即可复用。

---

## 一、三层结构

```
科目 Subject（math / english / politics）
 └── 章节 Chapter（如 函数、极限、连续）
      └── 知识点 KnowledgePoint（如 极限的四则运算与两个重要极限）
           └── 题目 Question（挂在知识点上）
```

**关键点**：掌握度是**挂在知识点上**的，不是挂在题目上。题目可以无限增加，知识点体系保持稳定。
这也是为什么第一批要先把章节和知识点树搭出来——它比题目更重要。

---

## 二、文件约定

| 项目 | 约定 |
|---|---|
| 存放位置 | `src/main/resources/data/` |
| 命名规则 | `{科目}-seed-batch{N}.json`，如 `math-seed-batch1.json` |
| 编码 | UTF-8（无 BOM） |
| 数学公式 | 第一批使用纯文本记法（如 `lim(x→0) sin(3x)/x`）。若改用 LaTeX，JSON 里的反斜杠必须写成双反斜杠 |

---

## 三、顶层字段

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `schemaVersion` | String | 是 | 格式版本，当前 `1.0` |
| `batch` | String | 是 | 批次标识，如 `math-batch-1` |
| `title` | String | 是 | 批次标题 |
| `createdAt` | String | 是 | 创建日期 |
| `scopeNote` | String | 是 | 范围与合规说明（必须写明"原创、不照搬真题"） |
| `subject` | Object | 是 | 科目信息 |
| `chapters` | Array | 是 | 章节列表（含知识点） |
| `questions` | Array | 是 | 题目列表 |

### subject

| 字段 | 说明 |
|---|---|
| `code` | 科目代码：`math` / `english` / `politics` |
| `name` | 科目名称 |

### chapter

| 字段 | 说明 |
|---|---|
| `code` | 章节代码，如 `MATH-01` |
| `name` | 章节名称 |
| `order` | 排序号 |
| `applicableTo` | 适用卷种数组：`math1` / `math2` / `math3`。用于前端按考生类型过滤 |
| `points[]` | 知识点数组 |

### point

| 字段 | 说明 |
|---|---|
| `code` | 知识点代码，如 `MATH-01-01` |
| `name` | 知识点名称 |
| `order` | 排序号 |

---

## 四、题目字段（核心）

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `code` | String | 是 | 题目唯一编号，如 `MATH-Q0001`。全库唯一 |
| `subjectCode` | String | 是 | 所属科目代码 |
| `chapterCode` | String | 是 | 所属章节代码，必须是 `chapters` 里存在的 |
| `pointCodes` | Array | 是 | 关联知识点代码数组。**必须存在于 `chapters[*].points` 中** |
| `type` | Enum | 是 | 题型，见下表 |
| `difficulty` | Int | 是 | 难度，1–5（1 最易） |
| `year` | Int | 否 | 年份。原创题为 `null` |
| `source` | Enum | 是 | 来源，见下表。**合规关键字段** |
| `stem` | String | 是 | 题干 |
| `options` | Array | 是 | 选项数组。客观题填 `{"key":"A","content":"..."}`，非客观题填 `[]` |
| `answer` | String | 是 | 答案。客观题填选项 key（如 `B`），填空题填结果 |
| `explanation` | String | 是 | 解析。**必须说明解题思路，不能只给结论** |
| `keywords` | Array | 是 | 考点标签，用于检索与错题归因 |

### type 枚举

| 值 | 含义 |
|---|---|
| `SINGLE_CHOICE` | 单选题 |
| `MULTI_CHOICE` | 多选题 |
| `FILL_BLANK` | 填空题 |
| `CALCULATION` | 计算题 |
| `PROOF` | 证明题 |

### source 枚举（合规关键）

| 值 | 含义 | 用途 |
|---|---|---|
| `ORIGINAL_SEED` | 我们原创编写的种子题 | **测评用**（权威、可验证） |
| `AI_GENERATED` | AI 生成的题 | 仅用于强化练习，前端必须标注"AI 生成" |
| `USER_IMPORT` | 用户导入 | 用户自己提供的题 |
| `PUBLIC_OFFICIAL` | 官方公开资料 | 教育部/考试中心公开发布的样题、大纲 |

> **设计原则**：测评只用 `ORIGINAL_SEED` 和 `PUBLIC_OFFICIAL`；
> `AI_GENERATED` 只用于强化练习。这样既保证测评可信，又规避 AI 出题错误带来的风险。

## 五、完整示例

```json
{
  "code": "MATH-Q0001",
  "subjectCode": "math",
  "chapterCode": "MATH-01",
  "pointCodes": ["MATH-01-01"],
  "type": "SINGLE_CHOICE",
  "difficulty": 1,
  "year": null,
  "source": "ORIGINAL_SEED",
  "stem": "极限 lim(x→0) sin(3x)/x 的值为（　）",
  "options": [
    {"key": "A", "content": "0"},
    {"key": "B", "content": "1"},
    {"key": "C", "content": "3"},
    {"key": "D", "content": "不存在"}
  ],
  "answer": "C",
  "explanation": "令 t = 3x，则 x→0 时 t→0，且 x = t/3。于是原式 = lim(t→0) sin t / (t/3) = 3·lim(t→0) sin t / t = 3×1 = 3。这里用到第一个重要极限。最高频的错误是选 B——分子是 sin(3x) 而不是 sin x，凑出来的系数 3 不能丢。",
  "keywords": ["重要极限", "等价无穷小", "变量代换"]
}
```

## 六、生成与校验

题目**不要手写 JSON**（数学公式转义极易出错），用生成器脚本：

```
scripts/build_math_seed_batch1.py   生成第一批
scripts/validate_question_bank.py   校验所有题库文件
```

运行方式（项目根目录）：

```bash
python scripts/build_math_seed_batch1.py
python scripts/validate_question_bank.py
```

校验项：JSON 合法性、题号重复、必填字段、题型枚举、难度范围、
客观题答案是否在选项内、知识点引用是否存在。

## 七、数据库映射

| JSON | 数据库表 |
|---|---|
| `subject` | `subject` |
| `chapters` | `subject_chapter` |
| `chapters[*].points` | `knowledge_point` |
| `questions` | `question` |
| `questions[*].options` | `question.options`（JSON 列） |

掌握了这套映射，后续只要往 `data/` 里加新的批次文件，导入器无需改动。

- 缺少综合题、证明题（CALCULATION / PROOF 题型）

## 九、英语 / 政治批次（english-batch-1 / politics-batch-1）

同一格式，新增科目只需在 `data/` 放文件 + 在 `QuestionDataInitializer` 的 `SEED_FILES` 登记：

| 批次 | 章节 | 知识点 | 题目 | 题型 |
|---|---|---|---|---|
| english-batch-1 | 4（词汇语法/完形/阅读/写作翻译基础） | 12 | 26 | 单选 23 + 填空 3 |
| politics-batch-1 | 5（马原/毛中特/史纲/思修/形策） | 10 | 24 | 单选 22 + 填空 2 |

设计约定：
- **掌握度按知识点隔离**：知识点 code 带学科前缀（`MATH-` / `ENGLISH-` / `POLITICS-`），
  学生各科学情互不影响；导入与诊断都按前缀过滤，**无需给知识点表加学科列**。
- **导入按科目幂等**：`QuestionDataInitializer` 按 `subject_code` 判断该科目是否已导入，
  老库（只导过数学）重启后会自动补齐英语、政治，不重复导入。
- 英语、政治的翻译/写作为主观题，自动判分链路暂不覆盖，故只收客观题；
  后续扩批次时继续沿用同一格式即可。
